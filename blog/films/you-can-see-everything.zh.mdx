今天在电影院看了 A24 的纪录片《You Can See Everything》，全场爆满。我和 Jiayin 都是带着完全空白的预期去看这部电影的。我们事先既不了解 Nathan Fielder，也不了解 Elizabeth Holmes 和 Billy Evans，更不知道 Theranos 公司的诈骗事件。

看完后我才了解到，Theranos 竟然是硅谷历史上如此轰动的一起诈骗案，牵扯到的人员和涉案金额都如此庞大。更戏剧性的是，Liz 的父亲 Christian Holmes IV 曾经是另一家臭名昭著的诈骗公司安然（Enron）的副总裁。某种意义上也是子承父业了。

# **尴尬诡异的前一个小时**

在影片开头的一个多小时里，我只看到了一部充斥着《方形》式尴尬幽默的聊天电影。电影似乎在告诉观众，Liz 是一个精神状态非常古怪、不同于常人的女人。她对语言和情绪有着自己独特的理解，似乎永远都在表演悲伤和快乐，常常无法与别人达成最基本的共识。而她的伴侣 Billy，则似乎有着极强的控制欲。

导演 Nathan 极力地想要看见 everything，想要通过摄影机记录真实的他们。于是，在 Liz 入狱前的最后34天，Nathan 和摄制组住进了他们家。他与他们共同生活、交谈，甚至一起观看根据 Liz 的经历改编的电视剧《The Dropout》。

但这一切似乎都无济于事。Nathan 依然像是面对着两团迷雾，无法理解 Liz，也无法判断 Billy 究竟在想什么。在 Liz 入狱前，她久久地注视着 Nathan，似乎想要说些什么，却最终什么也说不出来。

# **摄像机之外**

而从 Liz 入狱以后，这部电影突然开始起飞。它从一部充斥着尴尬幽默的普通纪录片，逐渐变成了一部令人难以置信的 Meta 艺术作品。电影不断拓宽自己的叙事边界：最开始，摄影机只拍摄被观察者；随后，导演 Nathan 自己进入电影；再后来，整个摄制组也进入了电影。但这些都不够，我们仍然无法看见 everything。

那么，如何才能让观众看见摄影机之外的东西？

让演员把那些没有被拍摄到的、甚至不被允许拍摄的场景重新演出来吧！于是，电影进入了戏中戏。

Amanda Seyfried，一位曾经在电视剧《The Dropout》中扮演过 Elizabeth Holmes 的演员，如今又在这部纪录片里扮演 Elizabeth Holmes 本人。这实在是一个令人拍案叫绝的设计。一个演员，先是在虚构作品中扮演现实人物，如今又进入一部关于这个现实人物的纪录片，重新演绎那些真实发生、却没有被摄影机记录下来的事情。他们重现了 Liz 和 Billy 生活中的小片段，也重现了电影立项阶段导演、制作组与两人交谈的过程。

甚至在重演中，观众逐渐发现，Billy 曾经试图通过这部纪录片获得经济利益，而 Liz 对此似乎并不知情。难道 Liz 一直被 Billy 控制着？观众就像扮演 Liz 的 Amanda 一样，急切地想要了解这一切，试图从不断浮现的细节中拼凑出这段关系的真相。

看到这里，我脑海中只有一个评价：电影之神显灵**。**

但，这就是真实吗？

这就意味着我们终于能够看见全部了吗？

电影并没有止步于此，Nathan 并没有避讳自己在重演过程中仍然会修改演员的台词、调整表演，甚至主动引导演员朝某种情绪和解释靠近。而且，他自己也并不是一个没有立场的观察者。就像他和 Amanda 讨论的那样，不知为何，他们都倾向于相信 Liz 对分红一事确实不知情。即使他们也考虑过另一种可能：Billy 负责干脏活，而 Liz 负责扮演傻白甜，两人共同维持着这种表面上的权力关系。他们却仍然更加愿意相信 Liz。

在搜索资料的过程中，我发现 Nathan Fielder 之前的一部作品《The Rehearsal》有着类似的创作逻辑。

在那部作品中，他为现实中的人搭建精细的模拟环境，让他们提前排练未来可能发生的生活事件。他甚至会重建真实的房屋、雇用演员扮演现实人物，试图通过反复排练来理解和控制那些尚未发生的事情。而在《You Can See Everything》中，他几乎反过来做了同一件事：他不再排练未来，而是试图重演过去。

但无论是排练未来还是重演过去，都会遇到同一个问题：当你试图通过表演去理解现实的时候，表演本身已经成为了现实的一部分。而且，Nathan 本人也早已进入了这个循环。他不仅是导演，也是电影中的人物；不仅在观察别人，也在被别人观察；不仅试图揭穿别人的表演，自己也在扮演一个试图揭穿真相的导演。

导演本身，也成为了一个不可靠的叙述者。

这正是电影震撼我的地方。它记录的并不只是被拍摄者的谎言，还逐渐把观众怀疑的对象从被拍摄者转移到了导演、摄制组、演员，乃至观众自己身上。

这一点也直接被扮演 Liz 的女演员 Amanda 指出：Nathan 自己也带着情绪、判断和偏向来拍摄这部电影。既然导演自己也有立场，那么他所呈现的所谓真实，究竟又有多少是他希望观众看见的东西？

在电影的最后，Nathan 和 Amanda 重现了因为法律原因无法直接录制的 Nathan 与 Liz 的电话谈话，以及监狱探视。这些新的信息，又让此前看似逐渐清晰的关系重新变得模糊。所谓的控制与被控制，似乎又需要打上问号。这对夫妻之间究竟是爱情、虐待、依赖，还是欺骗？又或者，这些关系本来就可能同时存在？外人真的能够理解他们吗？

当然，我们无法完全理解他们的私人关系，并不意味着 Holmes 已经被司法认定的欺诈行为也因此变得不可判断。私人生活的复杂性，不能抹去公共事实。但在这段婚姻里，镜头显然仍然有无法抵达的地方。

影片结尾，观众隔着监狱的围栏，看着 Billy、Liz 和他们的孩子们一起玩耍。我们已经看过了那么多对话、采访、幕后争执和重演，知道了比电影开始时多得多的信息。可是，此时此刻，拨开层层迷雾的我们，依然像是在注视着一团迷雾，仿佛永远没有尽头。

# **虚构与真实的边界**

这让我想到了伊朗导演阿巴斯·基亚罗斯塔米的《特写》，以及他的柯克三部曲：《何处是我朋友的家》《生生长流》和《橄榄树下的情人》。

柯克三部曲有一个极其巧妙的递归结构。第一部电影讲述一个孩子寻找同学家的故事。第二部电影则让一位导演在地震后寻找第一部电影中的演员。而到了第三部，第二部电影的拍摄过程又成为了故事本身。每一部电影都在试图揭示前一部电影镜头之外的世界，但当我们终于来到镜头之外，却发现那里又有新的摄影机、新的表演、新的故事。

阿巴斯在《特写》里则更进一步，让真实案件的当事人重新扮演自己，把纪录与虚构交织在一起。这与《You Can See Everything》有着惊人的相似性。

说到戏中戏，就不得不提一句库斯图里卡的《地下》。它通过戏中戏、戏中戏中戏，以及人物不断重叠的身份，把历史、谎言、戏剧和现实编织成一个荒诞的梦境。

虽然出于完全不同的目的，但这些大师之作尝试打破电影与现实之间界限的方式，都令人十分着迷。

跳出电影，在游戏界，也有着许许多多的 Meta 和 ARG 游戏，试图跳出游戏，直接与玩家对话，甚至脱离游戏本体，进入电脑乃至现实世界当中，试图成为真正发生的事。

但《You Can See Everything》又有一个特殊之处：不好意思，这是一部纪录片，而不是虚构作品。

但这在电影史上并非孤例，至少我觉得中国导演大鹏的《吉祥如意》有异曲同工之妙。

这部电影同样有着明显的前后两部分：《吉祥》原本试图通过职业演员与真实家庭成员的互动，讲述一个家庭的故事，而《如意》则把前一部分的拍摄过程也纳入了电影。随着真实人物和家庭矛盾逐渐进入镜头，原本的创作计划开始失去控制，电影本身也发生了变化。

《吉祥如意》和《You Can See Everything》在制作规模、人物背景和事件的社会影响力上当然完全不同，但两部电影都让我感受到了一种相似的奇妙：导演试图安排现实，让现实按照自己的创作计划发展，结果现实却反过来改变了电影。尤其是两部作品都在前后两部分之间发生了形式上的转变，让原本处于摄影机背后的创作过程，成为了电影真正重要的内容。

如果说《吉祥如意》是一次意外的电影之神显灵，那么《You Can See Everything》则像是导演主动追逐这种可能性，最后竟然真的追到了。

它所面对的并不只是导演编造出来的人物，而是真实存在、会撒谎、会改变主意、会反抗导演，也会受到电影影响的人。甚至导演自己都无法预料这些人的行为将把电影引向何方。这让它从一部有着巧妙形式设计的佳作，变成了一种极其罕见的电影体验。

当然，这种创作方法并非完全无法学习。阿巴斯早已证明，电影可以通过重演现实来质疑现实；大鹏在《吉祥如意》中也让拍摄过程与现实生活相互影响；Nathan 自己更是早就在《The Rehearsal》中探索过类似的方法。但我觉得，这部电影最终呈现出来的结果几乎无法复制。因为你可以复制它的形式，却无法复制它与真实世界发生碰撞时产生的偶然性。一旦试图刻意重现这种偶然，它就可能成为另一场表演。

我还很庆幸，至少从影片呈现的结果来看，Billy 并没有如愿通过这部电影获得他想要的分红。否则，事情甚至还会多出一个极其讽刺的层次：观众为了揭穿这个人的真实面目而购买电影票，却可能因此直接为他创造收益。那时，观众的观看行为本身就会成为电影所讨论的操纵、利益与表演关系的一部分，而且可能是一个相当负面的 Meta。

# **总结**

其实就像《一一》里洋洋想让别人看到自己看不到的另一半，于是拍摄他们的后脑勺一样，Nathan 不仅想拍到人物的正面和背面，还想拍到他们的家庭、过去、秘密、谎言，甚至那些摄影机从未到达过的地方。

于是他不断增加摄影机，不断增加叙事层级，不断重演那些没有被记录下来的事情。但每增加一层叙事，我们就多了一层需要怀疑的东西。

摄影机并不是一扇透明的窗户。它总是有一个位置，有一个角度，有一个操作者，而操作者又有自己的情绪、偏见、欲望和判断。

电影中的人物可能在表演，导演可能在表演，演员在重演别人的表演，而观众又在根据这些表演推测所谓的真实。

我们似乎永远无法从这个循环中逃脱。电影花了将近三个小时，让观众不断相信自己终于接近了真相，然后又一次次亲手推翻这种确信。

直到最后，镜头停留在监狱围栏之外，看着这一家人。我们已经看见了那么多，却仍然不知道自己究竟看见了什么。

**我们永远无法看见一切。**
