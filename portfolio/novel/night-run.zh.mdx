# 场景1 室内·便利店 - 夜

深夜的便利店内，白色日光灯照亮货架。**男主角**（戴着口罩和帽子，只露出眼睛）背对镜头，缓缓在货架间移动。他挑选了绳子、胶带、一卷塑料布等物品，拿在手里。店内悬挂的电视正在播放新闻：

**电视播音**（背景音，英语）：近日，本市连续发生数起女性失踪案件，警方怀疑是连环犯罪... *（声音模糊淡出）*

收银台前，**便利店店员**低头滑动手机，对新闻充耳不闻。他漫不经心地瞥了一眼电视，又继续刷手机。

男主角走向收银台，把物品放下结账。店员机械地扫描商品。男主角全程沉默，只是掏钱付款。店员抬头看他一眼。

**便利店店员 (英语)**：Have a good night.

男主角点点头，提起购物袋走出店门。

门外是空旷安静的街道，天空呈深蓝色——黎明前的蓝调时刻，夜色未尽。

男主角站在店外，将耳机塞入耳中。音乐响起——New Order的《Ceremony》。他顺着人行道开始跑动起来。

# 场景2 外景·街巷道路 - 夜

音乐伴随长镜头。男主角沿着寂静的街巷夜跑，镜头始终跟随他的背影。夜风轻拂，他拉低帽檐，拉高口罩，将脸遮住大半。四周街道空旷，偶尔路过零星的行人，也都行色匆匆，彼此漠然。

广角镜头下，路灯将男主角的身影投在人行道上，显得孤独而渺小。城市在夜色中冷漠寂静，只有他的脚步声和耳机里的音乐相伴。

男主角持续奔跑，穿过街区和小巷，最终跑进一片幽暗的公寓楼区。

# 场景3 室内·男主公寓 - 夜

男主角气喘吁吁地停在自己公寓门口。他摘下耳机，这时手机震动了一下，屏幕上跳出一条消息：“我到了。”

男主角看向门口，深吸一口气，伸手打开门。

门外站着一位比男主角年长几岁的**妓女**。她衣着时尚，嘴角带笑，也戴着口罩。看到男主角，她取下口罩，露出精致却略显风尘的面容。

**妓女（中文）**（笑盈盈地）：好久不见啊。

男主角微微一笑，让开门让她进来，顺手递给她一条干毛巾。

妓女接过毛巾，擦了擦因为夜晚有些湿冷而微微发红的脸。

**妓女（中文）**（打量男主角的运动装束，调侃道）：你跑步还真是坚持哦，每次来找你你不是刚跑完就是刚要去跑。

男主角有些局促地笑笑，关上门。妓女熟稔地脱下外套，露出轻便的穿着。男主角将购物袋随手放在床头柜上，一个小纸袋从中露出一角——里面装着刚才买的绳子和胶带。

妓女注意到袋子，扬起眉梢，眼中闪过一丝调皮。

**妓女（中文）**（语带玩笑）：哟？小弟弟今天……要玩点不一样的吗？

男主角愣了一下，还未回答。妓女已经走近他，嘴角带着暧昧的笑意，伸手勾住他的脖子。室内昏黄的灯光下，两人的身影靠得很近。

镜头转向窗帘，无人的窗边，窗帘在夜风中缓慢飘动；又转向地板，一条毛巾滑落在地。

房间里传来妓女略带喘息的声音。

**妓女（中文）**（笑声）：原来你喜欢这种——诶？等等……你——唔…！

妓女的语气从兴奋变为疑惑，又瞬间转为惊恐。她的笑声戛然而止，取而代之的是喉咙被压迫发出的嘶嘶声。挣扎声混杂着床板的轻微震动。

妓女的声音渐渐嘶哑，随后归于寂静。

黑暗骤然笼罩整个画面，所有声音归于无有。

黑屏中，缓缓浮现影片的片名：**《夜跑》**。

# 场景4 室内·男主公寓 - 日（过去的回忆蒙太奇）

*（黑屏结束，出现字幕：“数月前”。）*

日间，疫情期间的封闭生活通过一系列快节奏的片段闪过：

- 清晨的卧室，笔记本电脑屏幕上打开着视频会议界面，多名同事的小窗口闪动。声音叠加，各种英语对话混杂在一起：“...the figures for Q3... can you hear me? ...we need to pivot...”

男主角戴着耳机坐在电脑前开会，神情恍惚。他的摄像头关着，他默默听着，眼神却游离。

- 厨房里，男主角烧水泡方便面。水汽氤氲中，他望着窗外阴沉的天色出神。窗外的街道空荡荡，偶有人影经过，都戴着口罩匆匆赶路。
- 男主角独自坐在沙发上，一边懒散地吃泡面，一边滑动手机刷新闻。新闻充斥着疫情的数据和琐事，他麻木地划过。
- 黄昏时分，男主角站在阳台上远眺。几户邻居各自活动：有人提垃圾出门，有人在窗内望向外面。楼下人行道上，一个**女跑者**经过，步伐轻快地跑过公寓楼前的马路。男主角视线跟随她的背影一瞬，但没有任何交流。

画外传来男主角低沉的内心独白：

**男主角心声（中文）**：在城市里，每个人都只是过客，彼此看得见，却互不相干。

这一刻，男主角仿佛意识到了自己巨大的孤独，与城市格格不入。他低下头，走回屋内。

- 夜晚，客厅昏暗一片。突然，一阵手机铃声刺破寂静。

男主角接起手机，将其放到耳边。

**诈骗犯 (电话，中文)**（语气严肃正气）：您好，我们是中国警方调查科。您涉嫌一起金融犯罪，需要协助调查。

男主角一下紧张起来，从沙发上坐直。

**男主角（中文）**：什、什么？警方...? 出什么事了？

**诈骗犯 (电话，中文)**：我们发现您的身份信息涉及一桩跨国洗钱案。目前您是犯罪嫌疑人，请务必保密并配合我们的调查，否则将面临逮捕和遣返。

男主角瞪大眼睛，呼吸急促起来。

**男主角（中文）**：我...我没有... 我一直守法的！需要我怎么配合？

**诈骗犯 (电话，中文)**：我们需要您将您账户里的存款转到我们提供的安全账户，由检察官办公室核查资金来源。如果清白，资金会在24小时内返还。这是为了证明您的清白，请您理解配合。

男主角听到“证明清白”几个字，紧张中竟带着一丝莫名的兴奋和自豪。他仿佛成了一出大戏的主角，终于有机会“参与”一件大事。他连连点头：

**男主角（中文）**：好...好的，我配合调查。我现在就去准备转账。

镜头切换：男主角颤抖着打开手机银行，在诈骗犯的指示下，将毕生积蓄转到了所谓的“安全账户”。

时间跳切。几分钟后，电话挂断。男主角握着手机愣在原地，屏幕上银行余额变成了0。

他反应过来，给那个号码拨回去，对方已无法接通。这才意识到自己被骗，脸色由煞白转为涨红。

男主角手一松，手机掉在地上。他站在原地，双拳紧握，身体微微发抖，眼眶通红却没有流下泪。愤怒、羞辱和悔恨在他胸中翻腾，最终化作一声嘶哑的吼叫。他一拳砸在墙上，随即无力地滑坐到地板上。

- 数日后，夜晚的房间中，电脑屏幕闪烁着录像影像。男主角睁大红肿的眼睛，盯着屏幕上的犯罪纪实纪录片。

旁白声音从电脑传出（中文或英语，交替）：“…嫌犯作案手法拙劣，留下了大量证据…”，“…警方根据现场遗留的毛发锁定了目标…”，“…凶手最终在一次失误中露出马脚…”。

男主角眼中布满血丝，面前的笔记本上播放着各类真实犯罪播客、纪录片的片段。他如痴如醉，全神贯注。

镜头扫过他杂乱的房间，各处丢着打印的新闻、笔记本，上面潦草地写着文字：**“无身份者”、“无痕迹”、“延迟发现”、“第一现场”、“销毁证据”、“不在场证明”** 等要点触目可见。

男主角用笔在纸上狠狠画下最后一道线。他望着自己的这些笔记，嘴角露出一丝极淡的笑意，眼神空洞又炽热。他的脑海中开始勾勒一个疯狂的念头——只要计划周密，他是否也能尝试一次完美的犯罪？

他猛地摇摇头，用力揉了揉脸，似乎想把这些荒谬念头驱散。

**男主角心声（中文）**：不，不行…我在想什么？

镜头定格在他桌上的笔记纸，纸上写满了密密麻麻的中文笔记，几条关键原则被划上重点：

1. **目标**：选择社会不会在意的受害者。
2. **手法**：造成无痕迹的死亡，尽量避免直接痕迹。
3. **现场**：让尸体迟迟无法被发现，减少法医获取信息的机会。
4. **转移**：第一案发现场绝不能暴露。
5. **证据**：销毁物证，断绝线索。
6. **不在场证明**：确保自己案发时不在现场的证据。

男主角盯着这些原则，胸口急促起伏。他闭上眼睛，深呼吸几次，努力让自己冷静下来。

最终，他睁开眼，拿起桌角落灰的跑鞋穿上。

**男主角（自语，中文）**（声音低哑）：跑步…我得出去跑跑步，清醒一下。

# 场景5 外景·公寓附近荒地跑道 - 夜

皎洁月光下，男主角沿着公寓附近一片荒地的环形人行道慢跑。远处的城市灯火零星，周围环境空旷荒凉，只有几盏路灯孤独地照亮一小片路面，忽明忽暗。

每晚都有零散的跑者在这里夜跑。男主角偶尔与其他跑步的人擦肩而过，但彼此都沉默无言，只是匆匆错身而过。

他注意到其中有一个身影矫健的**女跑者**（就是之前楼下看见的女子），戴着耳机从他身边跑过。她身材高挑、动作利落，夜色中只能隐约看见她侧脸的轮廓。男主角鼓起勇气想打招呼，但对方目不斜视地跑远了，只留下一串渐渐远去的脚步声。

男主角有些失落地停下脚步，目送女跑者消失在黑暗中。他苦笑一下，继续跑完自己既定的圈数。

几周过去，男主角坚持每夜出来跑步。他多次远远地看见那个女跑者的身影，有时迎面跑过，有时在前方不远处。他俩总是在夜色中擦肩，却始终没有交谈。

某晚，月光黯淡，云层压低。男主角跑过一片居民区时，注意到前方一栋小房子的门半掩着，门口没有灯光透出，似乎家中无人。他迟疑了一下，心跳忽然加速——大门竟没有锁好？

四下无人，夜深人静。男主角犹豫片刻，终于鬼使神差地走上那户人家的台阶，轻轻推开门缝闪身进入。

# 场景6 室内·陌生人家客厅 - 夜

客厅昏暗，沙发和茶几的轮廓在微弱的路灯反光下可见。空气中有一种陌生家庭特有的气息。男主角屏住呼吸，蹑手蹑脚地走过客厅。他听到卧室里传出均匀的鼾声——屋主人正在熟睡。

男主角站在走廊，紧张又兴奋，仿佛一只潜入别人生活的幽灵。他没有再往里走，只是静静地站了几秒，然后轻轻退了出来。

# 场景7 外景·居民区街道 - 夜

男主角跑出那户人家，重新回到夜色的街道。他跑到对面的巷子里，靠着墙大口喘气，心脏剧烈跳动，脸上竟露出一丝难以抑制的兴奋笑容。

**男主角心声（中文）**（伴随急促呼吸）：我……我竟然真的进去了…没人发现…（他深吸一口气）天哪。

他闭上眼，沉浸在肾上腺素带来的快感中。

从那晚起，男主角对这种“潜入”行为上了瘾。此后几个夜晚，他的跑步变成了幌子，他尝试推开别的没锁的门，或者翻入人家的院子，在别人熟睡时进入那些陌生的空间，感受心跳加速的刺激。

镜头闪过几个场景：

- 男主角轻手轻脚地穿过一户人家的走廊，墙上家庭照中的人像在黑暗中注视着他的背影。
- 他从另一家的后门翻出，落荒而逃后躲在树后，掩嘴偷笑，似乎为自己的大胆感到不可思议。

某晚，夜凉如水。男主角按照惯例结束跑步，钻进一处相对熟悉的小别墅的后院。这户人家今晚漆黑一片，似乎没人在家或者都已熟睡。

# 场景8 外景·小别墅后院/荒地 - 夜

男主角猫着腰在后院的树影中移动。忽然，他的动作停住了——远处靠近后院篱笆的地方，有一道黑影正在地上拖拽着什么沉重的物体。沙沙声在寂静中格外刺耳。

男主角瞪大眼睛定睛看去，那黑影像是一个人，正把一大包东西往后院尽头的荒地里拖。他心跳再次狂飙，这一幕和他平日观看的犯罪纪录片何其相似。他下意识地想靠近看个究竟。

然而他刚迈出一步，脚下踩到了一根干枯的树枝，“咔嚓”一声轻响。

远处的黑影猛地停住动作，像是听到了动静。那人的头缓缓朝男主角藏身之处转来。

男主角大惊，来不及细看，转身拔腿就跑。他顺着来路狂奔离开院子，一口气跑出很远才停下。回头望去，黑暗中什么都看不见。

他冷汗直冒，颤抖着躲在一棵树旁，良久才缓过神来。

**男主角（喘息着自语，中文）**：刚才...那是...在拖尸体？！

他不敢相信自己所见，扶着树干的手在微微发抖。

天色微亮，男主角匆忙跑回家。一夜无眠。

# 场景9 外景·街头 - 日

次日清晨，男主角戴着口罩出门买咖啡。经过街角公告栏时，他的脚步慢下来。

公告栏上贴着一张**失踪启事**，标题写着：“寻人启事”。下面是一位年轻女性的照片和姓名，写明她已失联数日，家人正在寻找知情者提供线索。女青年是某个少数族裔的加拿大移民。

男主角盯着那照片，心头一震——直觉告诉他，这失踪的女孩，极可能就是昨晚那个黑影正在处理的“物体”。

他感到一阵眩晕，匆匆买了咖啡离开。

# 场景10 外景·荒地 - 夜

几天后，夜晚。男主角再次来到之前的荒地。这片空旷的草地在夜色下显得格外阴森，四周没有行人，也没有监控。他顺着模糊的记忆，找到那晚自己远远望见黑影的位置。

月光下，草丛中有一块略微隆起的新土，隐约呈长条状。男主角走近，心提到了嗓子眼。

他跪下来，伸出手小心地拨开一层松散的浮土。突然，露出了一截苍白僵硬的手指。

男主角猛地倒吸一口凉气，身体向后退缩，几乎跌坐在地。他惊恐地瞪着那从泥土中探出的死人手指，胸口剧烈起伏。四周死一般的寂静，只有他急促的喘气声。

他慌张地四下张望，这里离最近的人家也有一段距离，黑暗中没有任何人影或灯光。

男主角颤抖着掏出手机，按下了911报警号码。然而拇指悬在拨号键上，他犹豫了——如果报警，他要解释为何深夜出现在这里，又如何发现这尸体？会不会暴露他此前潜入人家的行为？

手机屏幕的911拨号界面幽幽发光，他的拇指最终还是慢慢松开，没有按下“呼叫”。

男主角缓缓放下手机，重新看向地上的尸体。他压下心中的恐惧，靠近一些，借着手机微弱的手电光仔细观察尸体露出的部分——一只瘦小的手掌，指甲上有残留的泥土，皮肤在月光下呈现诡异的青白色。

他的呼吸逐渐平稳下来，眼神发生了变化。从最初的惊恐逐渐转为某种冷静而理性的光芒。他的好奇心战胜了恐惧。

他伸出戴着手套的手（出门跑步时防寒佩戴的手套），轻轻触碰尸体的手腕和露出的一截手臂肌肤。冰冷，僵硬。他皱眉思索片刻，小声自语：

**男主角（低声自语，中文）**：死亡至少……有几天了。下手很重，没有外伤，可能是窒息或者毒杀？

他试图在尸体上寻找更多信息，但土埋的太多，无法轻易辨认死因。

远处隐隐传来雷声，天空开始飘起冷雨。

男主角缓缓站起身，退后两步，立在一旁凝视着地上浅埋的尸体。细雨逐渐变成瓢泼大雨，打湿了他的头发和衣服，但他似乎毫无所觉。

一道闪电划破天际，刹那的白光中，镜头仰视拍摄男主角伫立在雨夜里。他的身影被阴影笼罩，眼神幽暗，死死盯着地上的尸坑，雨水顺着他的下巴滴落。他握紧手机，心中一个大胆的想法迅速成形——**也许，这是一个机会**。

又一声沉闷的雷鸣炸响夜空。镜头视角骤然转为俯视，从高处直直向下看去：

雨中的泥土地面上，一具女性尸体静静躺在浅浅的坑穴中。那张苍白的脸正是**妓女**——男主角所杀的女人。她双眼紧闭，表情定格在痛苦中。雨水冲刷着她的脸和散乱的头发，混着泥土流进坑里。

（注：以上俯拍画面可视为时间线快进的象征性画面，暗示男主角很快将付诸行动，成为模仿犯。）

# 场景11 外景·街道小巷 - 夜（暴雨）

滂沱大雨倾泄在城市的街道上。男主角骑着一辆旧山地自行车，吃力地踩动脚踏，后座上捆绑着一个用黑色塑料布包裹的长条状物件——妓女的尸体。

他全身湿透，雨衣紧贴在身上，脸上雨水与汗水交织。他沿着事先规划好的路线小心前进，避开主要道路和可能的摄像头。偶尔远处有汽车灯扫过，他立刻闪进旁边的小巷，屏住呼吸等待车辆经过。

镜头采用主观视角（GoPro般摄像头在车头），透过雨水可以看到前方零星的街灯和漆黑的巷道，紧张而逼仄。

终于，他抵达那片荒地。四下无人，风雨交加中，他用尽全身力气将沉重的塑料裹尸拖下车，拉到先前发现尸体的不远处。他对照着之前看到的埋尸方式，用随身携带的铁锹疯狂地挖坑。

雨水不断灌进坑里，他的额头冒着青筋，双眼血红，但嘴角微微上扬，露出一丝偏执的笑。

镜头远远看着这疯狂又诡异的一幕：暴雨之夜，一个孤独的身影在泥地里拼命挖坑掩埋尸体，周围是一片黑暗的荒野。

# 场景12 室内·男主公寓 - 日

次日白天。男主角的公寓客厅里，电视机正开着，无人观看。新闻频道正在报道昨夜发现的一具女性尸体的消息。

**电视新闻主播 (英语)**：...the body of an unidentified female was discovered early this morning. Police have not released further details and are investigating possible links to other recent disappearances...

男主角坐在餐桌旁，对着一碗泡面发呆。电视的声音在空旷的屋里回荡，他脸上毫无表情，像是置身于真空。

他慢慢舀起一勺泡面汤，送入口中。新闻内容引不起他一丝波澜，他只是机械地吞咽。

**男主角心声（中文）**：她也不过是个异乡人，就像我。没人关心。

他放下筷子，眼神空洞地望向窗外。

一段记忆闪回：

夜色中，男主角屋内的灯光温暖，妓女（第一次上门交易时）坐在沙发上，手里捧着一听可乐，爽朗地笑着。

**妓女（中文）**：我啊，湖南人。你呢？咱俩算不算老乡？

男主角也笑了，举起自己的可乐罐碰了碰她的。他轻轻点头：

**男主角（中文）**：我是湖北的，挨着，很近。

两人惺惺相惜地笑起来。那一刻，他们像两个远离故乡的旧识，在异国他乡难得找到一丝亲切。笑声中，二人的身影显得不再那么孤单。

闪回结束。镜头回到此刻男主角的眼中。电视机的光在他瞳孔中闪烁，他却似乎走神了。嘴角的笑意早已不见，只剩下一抹难以言喻的落寞。

成功完成了一桩精心策划的犯罪，本应让他兴奋，可他内心却一片空虚。短暂的满足之后，更深的孤独如影随形。同时，他感觉自己某些地方变了，说不清是什么——眼神中多了几分偏执和警惕，整个人比以前更加大胆，又更加孤僻了。

男主角轻轻叹了口气，站起身来，拿起外套准备出门。他现在唯一的日常依旧是——跑步。

# 场景13 室内·便利店 - 夜

便利店亮白的灯光下，男主角走进店内，又一次来到上次购买工具的货架前。这回他只是随意浏览，像是在思考还缺什么。

突然，他的目光停住了：旁边，一个熟悉的女性身影正蹲下身，从架子下方拿起一卷结实的麻绳，放进购物篮。

男主角定睛一看，正是**女跑者**，此刻她穿着便装，正仔细挑选类似的工具——胶带、塑料袋、一次性手套等等，一一放入篮中。

男主角瞳孔一缩，心中掠过一丝难以言状的感觉：惊讶、疑惑，还有兴奋。他深吸一口气，鼓起勇气上前搭话。

**男主角（中文）**（试探地轻声）：这款胶带不太黏，粘了容易留胶。你可以买这种防水的，黏性好一点。

女跑者闻声抬头，看到是男主角，微微一愣，随即露出礼貌的微笑。她拿起男主角指的那卷防水胶带，看了看又看了眼他。

**女跑者 (英语)**：Oh... thank you. (略带笑意) You seem to know your tapes.

男主角耸耸肩笑了笑，用不太流利但还算清晰的英语回答：

**男主角 (英语)**：I... had some experience. (指了指货架上的绳子，也用英语) And this brand of rope, it's strong. It won't snap easily.

女跑者挑起一边眉毛，饶有兴趣地打量了男主角几秒。两人在货架前开始闲聊起来。

**女跑者 (英语)**（友好地）：We’ve met before, haven’t we? Do you usually run around this area?

**男主角 (英语)**（点点头，放松下来）：Yes, I run here almost every night. I think I've seen you out there too. By the field, right?

**女跑者 (英语)**（露出恍然的神情，笑了）：Ah, yes. I remember your face... well, your mask at least. (她开玩笑地指了指自己的口罩)

两人都笑了。气氛一下轻松许多。

他们各自结账，一前一后走出便利店。夜晚的空气清凉，街道上只有远处几盏路灯还亮着。

# 场景14 外景·街道 - 夜

女跑者和男主角并肩走在空旷的人行道上。两人拎着各自的购物袋，步调不急不缓。四周安静得只能听见他们的脚步声和偶尔几声虫鸣。

淡黄色的路灯光拉长了他们的影子，两个影子时而分开，时而重叠。

**女跑者 (英语)**（望着前方，自言自语般）：Sometimes I feel like a ghost... just drifting through this city, watching everything and everyone.

男主角侧头看她，只见她侧脸在暗淡灯光下有种恍惚的美。他犹豫一下，慢慢开口：

**男主角 (英语)**：I know the feeling. (顿了顿) This city... can be a lonely place.

女跑者听了，转头看向男主角，眼神里透出一丝理解和好奇。她微微一笑，点点头：

**女跑者 (英语)**：It really can.

两人继续走着，有一搭没一搭地聊些生活琐事和各自对这座城市的感受。夜风轻拂，场面竟有几分浪漫的错觉。

走到一栋公寓楼下时，男主角脚步放慢了。他回头望了望跟自己同行的女跑者，心跳不禁加快。

**男主角 (英语)**（试探地）：My apartment is just here... Would you like to... maybe come up for a drink or something?

女跑者注视着他，嘴角扬起笑意。她痛快地点头：

**女跑者 (英语)**：Sure, why not.

男主角露出欣喜的神色，赶紧在前引路。两人走进公寓楼门。

# 场景15 室内·男主公寓 - 夜

房门再次打开，男主角和女跑者一同走进昏暗的公寓。男主角打开灯，暖黄色灯光亮起，映出两人都有些潮湿的衣服（刚刚走了一段路，微微出汗）。

女跑者打量了一下男主角不大的居所，目光掠过简朴的客厅和半敞的卧室门。她把手中的购物袋随意放在沙发旁。

**女跑者 (英语)**（轻松地笑）：Nice place. Cozy.

**男主角 (英语)**：It's not much, but it works.

男主角关上门，有些紧张地走到厨房冰箱前。

**男主角 (英语)**：I have beer, or soda... Water?

**女跑者 (英语)**：Water’s fine.

男主角点点头，倒了两杯水过来，递给女跑者一杯。两人在沙发坐下，各自喝了一口水。

气氛有瞬间的沉默，但并不尴尬。两人都能听见彼此的呼吸慢慢加重，心跳在寂静中变得清晰可闻。

女跑者放下水杯，侧过身靠近男主角，眼中似有某种光芒在闪烁。

男主角喉结滑动，轻轻放下杯子，鼓起勇气伸出手揽住她的肩膀。女跑者没有抗拒，反而顺势靠进他怀里。

两人缓缓吻在一起。起初试探而温柔，随后愈发激烈。男主角抱紧女跑者，从沙发移动到床边，一路衣物散落。女跑者低低地笑着，主动迎上他的亲吻。

床边地毯上，男主角之前在便利店买的那捆绳子静静躺着，包装已经被拆开了一端。

男主角将女跑者轻轻推倒在床上，自己俯身压上去。两人气息纷乱，眼中燃着欲望的火。

男主角顺手拿起那捆结实的麻绳，动作几乎是本能般地，将绳子在女跑者纤细的手腕上绕了一圈。

女跑者没有挣扎，反而嘴角含笑地看着他，眼神挑逗而信任。她把双手自愿并拢，方便他捆绑，一副任他摆布的模样。

就在绳子即将收紧的一刻，男主角的动作突然停了下来。

他低头凝视着身下的女子，呼吸急促，内心却天人交战。这一幕何其熟悉——上一回，他也是这样绑住另一个女人的手，然后痛下杀手。然而眼前的这个女子，与之前的妓女又截然不同。

男主角的手开始发抖。他脑海中两个声音在撕扯：

**男主角心声A（中文）**：就是现在，动手！她也是猎物，而且更危险，更刺激…

**男主角心声B（中文）**：不，她跟你一样孤独，你其实并不想伤害她…你是喜欢她的，对吗？

他的额上沁出冷汗，绑着绳子的手停在半空，进退两难。

女跑者微微侧着头，用柔软的声音问出一句话：

**女跑者 (英语)**（声音轻如耳语）：Do you like me... or do you want to kill me? (眼神直视男主角) Or is it both?

男主角瞠目结舌，心跳仿佛停止了半拍。她的话击中了他的内心深处最不可告人的秘密。他不明白她如何看穿了自己，但此刻一切伪装都无所遁形。

他嘴唇动了动，却发不出声音。瞳孔微缩，手上的绳子不由自主地松开了一些。

就在这一瞬间，女跑者猛然翻身，身手敏捷得如同一只猎豹。她反抓住男主角的手腕，一个用力，便将他翻倒在床上。

男主角完全没料到她会反制，猝不及防之下被掀翻在下。他刚要挣扎，女跑者已然骑坐在他身上，夺过绳子一端，顺势一绕，牢牢套住了男主角的脖子！

**男主角**（惊恐地瞪大眼，本能地用手去扯绳子）：你——咳…！

女跑者俯下身，一只手稳稳收紧绳索，另一只手温柔地按住男主角试图反抗的双臂。她脸上竟浮现出一种近乎迷恋的神情，垂下眼睛凝视着他。

男主角脸涨得通红，双腿无助地蹬动。他的力气在绝望的窒息中渐渐流失。两人目光交汇，男主角从女跑者冷静深邃的眼神里读出了某种答案——原来她一直都是深渊的凝视者，而自己不过是一个自作聪明的模仿者。

男主角的挣扎变得微弱，手慢慢垂下，不再反抗。他眼角泛起泪光，喉间发出绝望的哽咽声。

女跑者凑得更近，几乎贴着他的脸颊轻声呢喃：

**女跑者 (英语)**（温柔低语）：You tried to be like me... but you'll never be me.

泪水从男主角眼角滑落。他瞳孔涣散，最终绝望地闭上了眼睛，仿佛接受了自己的命运。

女跑者眼中闪过一丝怜悯，又似乎夹杂着兴奋。她缓缓收紧绳索，将男主角紧紧勒入怀中，仿佛要给他一个永恒的拥抱。

她低下头，缓缓而深情地吻上男主角的唇。

男主角的身体在绳索最后的用力收紧下剧烈一颤，随即彻底瘫软下去，一动不动。

屋内只剩下女跑者轻微的喘息声。男主角的眼角还挂着未干的泪滴，瞳孔失去了光彩。

女跑者松开绳子，将男主角的尸体平放在床上，替他合上了眼睛。她坐在床边，静静凝视着他片刻，伸手抚去他脸上的泪痕和汗水，神情复杂难明。

片刻后，女跑者起身整理衣物。她俯视男主角安详却冰冷的面庞，低声呢喃了一句：

**女跑者 (英语)**（低沉喃语）：Good night.

她转身走出卧室。

镜头缓缓推远，定格在床上男主角逐渐冰冷的遗体。

# 场景16 外景·荒地 - 清晨

黎明时分，天光微明。晨雾笼罩在那片荒凉的空地上，一切寂静无声。

一双运动鞋踩入画面，踏在湿软的泥地上。镜头仰拍，只见**女跑者**已经换上了清晨慢跑的运动衣，戴着棒球帽和口罩，将半张脸掩映其中。

她微微闭眼，深吸一口清新的晨空气，然后开始沿着熟悉的荒地跑道慢跑起来。

朝阳的微光洒在她身上，她的背影与其他晨练者无异，逐渐融入城市的晨光中，消失在街道的转角。

镜头转向那片荒地的一角——泥土略显松动，隐约可见地下埋过什么。然而此刻四下空无一人，只有风吹动荒草，仿佛什么也没有发生过。

时间快进。延时摄影般的镜头下，天空从清晨转为白昼，又慢慢黯淡成黄昏，再到深夜，月升月落，如此反复，象征时间流逝了数日。

终于某个清晨，远处传来脚步声和人声。

**路人甲 (英语)**（远处，模糊听见）：Over here... I'm telling you, my dog was sniffing something...

镜头停留在荒地，以远景看去，两小个人影带着一条狗进入荒地。其中一个人影走近那片泥土松动之处。

忽然，一声凄厉的尖叫划破晨雾。

**路人甲 (英语)**（尖叫声）：Oh my God!!!

鸟群被惊起，扑棱棱飞向天空。

画面猛地切为黑幕。

几秒的死寂后，片尾音乐声响起——Re-Tros乐队的《Red Rum Aviv》低沉而诡谲的音符在黑暗中回荡。

*（剧终）*
